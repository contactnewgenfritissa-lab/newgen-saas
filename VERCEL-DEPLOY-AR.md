# النشر على Vercel
1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. افتح Vercel واختر Add New > Project ثم Import للمستودع.
3. Framework Preset: Next.js.
4. أضف متغيري البيئة:
   - NEXT_PUBLIC_SUPABASE_URL
   - NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
5. اضغط Deploy.
6. أضف رابط Vercel في Supabase Authentication > URL Configuration كـ Site URL وRedirect URL.
